# 书台：木色视觉方案第一版

本批为 v0.4.0 后的视觉尝试，不移动该标签。设计方向由用户确定：木色为主，浅橡木、纸白、胡桃木，少量苔绿；保留当前页头、波浪、图文卡片与侧栏。

## 色彩分工

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | #F5F2EC 米灰纸白 | #201D19 深木炭 |
| 阅读/卡片面板 | #FFFDFA 象牙白 | #2B2621 深胡桃 |
| 正文 | #332E28 暖墨 | #EAE2D6 暖纸白 |
| 次级文字 | #72675B | #B9AC9B |
| 主色、链接、焦点 | #805735 胡桃棕 | #D6AF7C 浅木色 |
| 柔和强调 | #EDE1D0 | #3B3026 |
| 辅助色 | #58674F 苔绿 | #A9B79B 灰绿 |
| 代码背景 | #F0EBE3 | #241F1B |

分类入口使用两档橡木渐变，每第三项使用苔绿；标题与数量采用相应深/浅文字，而非浅木色上放白字。数量取消淡化，让小字在装饰符后仍保持清晰。深色模式另设分类背景与文字色，不反转整页颜色。

页头使用暖中性遮罩，图片内容不改；无图片时为胡桃木渐变。保留白色页头文字与焦点轮廓。纸白卡片、暖灰边线与低强度棕色阴影形成层次，不增加纹理文件、字体、动效或图片请求。

正文引用使用浅苔绿面板与苔绿边线，表头使用浅木色，代码用独立纸灰背景。高亮采用砖棕、苔绿和木色，深色模式对应浅色高亮。目录当前项、分页、链接、按钮及可选资源沿用语义变量；浏览器 theme-color 同步为纸白/木炭色。

## 维护位置

- [tokens.css](../../src/styles/tokens.css)：基础颜色、分类渐变、页头背景与遮罩、代码色及阴影。
- [site.css](../../src/styles/layouts/site.css)：分类颜色分配与页面组件。
- [article.css](../../src/styles/markdown/article.css)：引用、表头、代码背景。
- [theme.ts](../../src/client/theme.ts) 与 [head.njk](../../layout/_partials/head/head.njk)：浏览器 theme-color 的初始值与切换值，改页面底色时需同步。

无需修改文章或用户封面路径。现有城市页头仍保留冷色光线，用于观察木色界面与不同内容图片的搭配；没有将用户图片统一染棕。

## 验证（2026-09-22）

Node 20.19.2、Chrome 151、Puppeteer 5.5.0、axe-core 4.13.0。基线 b241988（v0.4.0），当前工作树包含本批样式及 theme-color 修改。

- 构建、lint、typecheck 与 67 项测试通过，示例、Markdown、订阅和资源预算检查通过。
- 176 组响应式、66 组无 JS 回归通过；90 组核心页面 axe 扫描无 violations，18 组跳转链接和 18 组 200% 根字号检查通过。
- 上述矩阵后仅取消分类数量透明度；对最终样式额外检查首页、阅读元素、代码页 × 桌面/手机 × 深浅色共 12 组对比度和 theme-color。
- 主要正文/链接及代码色在对应实色背景上对比度均大于 4.5:1；渐变/图像、滚动区域仍有 axe incomplete，不能等同于完整 WCAG 认证。页头遮罩保持足够深度，色彩未增加图片亮度。
- 人工查看桌面浅色首页、桌面深色文章、手机首页与代码/引用页面截图。原有布局、图片、正文结构保留；无 JS 和 reduced-motion 行为不变。
- 最终核心 JS/CSS gzip 为 2026/5649 bytes，仍在预算内。此批没有重新运行 Lighthouse/INP，G4a 数值是旧视觉基线的历史结果，不能视为本批新测结果。未连接真实评论服务或重跑可选服务全部专项验收。

机器摘要见 [验收数据](../validation/wood-palette.json)。完整原始报告和截图在 `/tmp/syutoi-wood-a11y/`、`/tmp/syutoi-wood-browser/`；可复用 [开发说明](../development.md) 中的浏览器与无障碍脚本生成。此版用于实际浏览后继续调整木色浓淡、苔绿比例和层次，G5/G6 暂不推进。
