# E3 文章元信息与阅读时间验收

2026-09-20 完成。发布日期、跨日更新时间、作者与阅读时间集中在文章头部；独立 Page 不显示文章专用日期或阅读时间。文章及 Page 支持可选 cover_alt，无封面不增加图片占位。

## 估算规则

阅读时间在构建阶段从 renderer 输出的正文 HTML 计算，不增加浏览器依赖：中日韩文字每分钟 300 字，其他字母/数字词每分钟 200 词，混排相加向上取整。有正文的短文最少约 1 分钟；空、仅图片或仅代码块不输出。代码理解、图片理解、实际阅读行为及精细语言分词不在估算范围内。

`post.reading_time: false` 全局关闭，文章 `reading_time: false` 可单独隐藏，单篇 true 不覆盖全局 false。HTML 排除与计数范围见 [配置说明](../../example/source/_posts/theme-docs/configuration.md#阅读时间与封面替代文字)。这是粗略预计，不应称为实际耗时或准确字数。

## 复查方式

运行 `pnpm build && pnpm test` 可重复执行算法和 Hexo 渲染检查。启动预览后按 D7 环境运行 `toolbox/check-browser.mjs` 进行完整回归。

手动查看 `/syutoi-long-read/`、`/syutoi-minimal/` 和 `/examples/english/`：前两者应有本地化预计阅读时间，英文 Page 不显示；长文封面带替代文字，无封面文章不预留图片区。将单篇 reading_time 设为 false、或全局 post.reading_time 设为 false 后重新生成，估时应消失。将 updated 改为与 date 不同的日期，应只在头部显示一次更新时间。
