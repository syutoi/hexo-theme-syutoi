# F4：Feed 与 Sitemap 插件验收

日期：2026-09-22。Node 20.19.2、pnpm 9.0.4、Hexo 8.1.2。

## 插件与职责

沿用 hexo-feed 1.1.2 / hexo-renderer-ejs 1.0.0，示例站增加 hexo-generator-sitemap 3.0.1。插件是博客依赖，主题没有新增生成器或第三方浏览器请求。主题仍提供 RSS/Atom/JSON Feed 模板，Sitemap 使用插件默认模板。

修正 RSS HTML 二次转义、不规范的分类字段及 Atom 修改时间来源；补齐主订阅自引用地址。页面订阅发现链接在插件未注册生成器时省略。

## 验证结果

- lint、clean、typecheck、build、`pnpm test`、`git diff --check` 通过。
- 65 项测试通过，新增 4 项真实插件集成测试；根目录和 `/blog/` 两种部署均通过。
- XML 使用 saxes 严格解析，验证命名空间、特殊字符、HTML 正文、分类、发布时间与修改时间、自定义 feed/sitemap 路径。
- 草稿与未来文章（future:false）不出现；未发布文章不进入 feed；显式 sitemap:false 的文章/Page 不出现于 Sitemap；普通 Page 不出现在 feed。
- 未安装插件、分别关闭 feed、空站点均正常。空站点的 feed 仍有效，Sitemap 无输出；不存在的订阅路由不被 HTML 宣传。
- 示例站三种 feed 各 20 篇，RSS/Atom/JSON 的正文一致，Atom/JSON 修改时间一致；Sitemap 的 54 个唯一 URL 均指向本地已生成文件。
- 原有 19 个页面、20 个示例链接、Markdown 和独立资源预算检查通过。`git diff --exit-code -- source/js source/css` 通过，客户端资源未改变。

## 边界

这里只验证插件生成与本地输出，没有推送、部署、提交搜索引擎或验证实际订阅软件。hexo-feed 的 peer 范围仍不含 Hexo 8，测试结果不扩展其官方声明；保留该插件以兼容已有三类订阅配置与 JSON Feed。未同时引入其他 feed 生成器。

seo.noindex 不自动变为 sitemap:false，后者也不排除 feed。自定义隐藏内容须根据各插件能力分别配置。本阶段不验证分类/标签拆分 feed、JSON-LD 或内容访问控制。完整配置和已验证的排除规则见 [订阅与站点地图](../../example/source/_posts/theme-docs/syndication.md)。
