# E2 响应式目录验收

2026-09-20，在 0.1.0 MVP 后增加目录增强，记录于 CHANGELOG 的 Unreleased。本批没有改变页头、波浪、卡片或文章配色。

## 实现与行为

- 桌面（>=761px）沿用作者侧栏，在向下阅读时固定目录，最大高度受视口限制，长目录内部滚动；sticky 限制在侧栏所属布局区域内，不覆盖页脚。
- 手机（<=760px）在封面与正文之间显示默认折叠的原生 details。Enter/Space 展开，目录链接仍是原生锚点，不强制收起或拦截历史记录。
- 同一份 Hexo toc 输出用于两种呈现，CSS 只显示一种，标题 ID 不重复。无 JS 时仍可阅读、折叠与跳转；滚动高亮作为增强功能。
- JS 将越过视口顶部 96px 的最后一个可见标题标记为当前位置；首标题之前不高亮，页面底部处理无法靠近阅读线的末尾标题。使用 aria-current、字重和下划线，不仅依赖颜色。
- 滚动检查通过 requestAnimationFrame 合并，响应窗口大小、hash、load、toggle 和可用的 ResizeObserver。长桌面目录只滚动自身以显示活动项；焦点位于目录内时停止自动滚动。手机展开状态由原生控件管理，不存入偏好。
- 目录焦点跨断点时转到可见的对应链接，必要时展开手机目录；其他焦点不受影响。无 JS 不提供该额外焦点迁移。
- 无标题、toc: false、sidebar.toc: false 或 sidebar.enable: false 时不输出目录，适用于文章及独立 Page。

## 实测

环境：Linux、Node 20.19.2、Chrome 151.0.7922.108、已有 Puppeteer 5.5.0、127.0.0.1:4000 示例预览。手机检查为桌面视口模拟，不是真机。

| 检查 | 结果 |
| --- | --- |
| 桌面双向滚动、sticky 与单一当前项 | light/dark 通过；滚动不抢焦点 |
| 手机 Enter/Space 折叠、锚点与刷新 | light/dark 通过 |
| 目录焦点 390→1440→390 | 对应链接保持可见，手机按需展开 |
| 动态增加正文高度 | 未额外滚动时重新计算当前项 |
| 1440×320 短视口、长 Page 目录 | 内部滚动显示活动项 |
| 320px 长标题、重复标题、空正文 | 无整页横向溢出；无标题不输出目录 |
| 禁用 JS，1440/390/320px | 原生目录链接及手机折叠通过 |
| 缺少 ResizeObserver | 滚动高亮回退通过 |
| 既有浏览器矩阵 | 176 组有 JS、66 组无 JS 及主题/复制/键盘/reduced-motion 全部通过 |
| 脚本错误 | 0 |

专项结果见 [e2-toc.json](e2-toc.json)，综合记录见 [e2-browser.json](e2-browser.json)。输出 4 张专项截图到 `/tmp/syutoi-e2/`，人工检查桌面浅色固定目录及手机深色展开目录；综合脚本另保存 8 张截图到 `/tmp/syutoi-e2-matrix/`。

lint、typecheck、干净构建（99 文件）、42 项测试、19 类页面、20 个示例入口链接与 Markdown 产物检查通过。新增的 Hexo 测试覆盖两种目录目标一致、重复标题和站点开关；已有测试继续检查 page.toc 与空页面。

核心 JS gzip 2028 bytes、CSS gzip 5382 bytes（level 9），均低于预算。本批未运行新的 Lighthouse 或真实 INP 测量；D8a 仍是此前版本的性能记录。未测试 Safari/Firefox、屏幕阅读器或完整 WCAG。历史友链外部图片与故意失效示例资源仍按 D7 范围处理。

最后补充 600/760/761px 边界检查：手机作者卡片居中且填满 360px 面板，761px 正常恢复桌面侧栏，均无整页溢出。此卡片对齐调整之后再次构建及运行 42 项测试通过。

## 重复运行

先运行 `pnpm dev`，使用 D7 所述外部 Puppeteer/Chrome 环境：

```bash
export SYUTOI_BROWSER_OUTPUT=/tmp/syutoi-e2
node toolbox/check-toc.mjs
export SYUTOI_BROWSER_OUTPUT=/tmp/syutoi-e2-matrix
node toolbox/check-browser.mjs
```

可用 `SYUTOI_PREVIEW_URL` 修改预览源地址。两个脚本都不加入默认构建/CI，也不下载浏览器；失败时以非零状态退出。
