2026-09-19 完成，测试对象为 D5 提交 `d6244e8` 的主题与示例站。本批新增验收脚本与记录，没有修改主题运行时代码或样式。

原始逐项结果见 [d7-browser.json](d7-browser.json)，可重复运行的脚本为 [check-browser.mjs](../../toolbox/check-browser.mjs)。

| 检查 | 结果 |
| --- | --- |
| 22 页面 × 4 屏宽 × 2 系统颜色 | 176 组通过；HTTP 200、main 有内容高度、实际主题匹配、无整页横向溢出 |
| 22 页面 × 3 屏宽 × 无 JS | 66 组通过；导航可见、增强按钮隐藏、正文可读、无整页横向溢出 |
| 键盘导航 | Tab/Enter 跳至正文，焦点框可见；Space 展开、Escape 收起、Tab 自然离开；跨断点焦点正确转移 |

| 代码复制 | 缩进、空行、制表符、行末空格和 br 保真；成功/拒绝/重试提示正常；键盘焦点保留 |

复制使用可控制的 Clipboard API 替身验证成功、拒绝与重试，没有改写系统剪贴板；这不是所有浏览器真实权限弹窗的验证。主题存储受限通过让 localStorage 访问抛错模拟。

桌面/手机、深浅模式共输出 8 张首页与文章截图，保存在本次运行的 `/tmp/syutoi-d7/`；人工查看了手机深色首页和桌面浅色文章截图。图片不随仓库提交，重新运行可生成。

## 已知范围

- 唯一被拦截的外部资源是历史友链内容中的图片 `https://cdn.jsdelivr.net/gh/amehime/shoka@latest/images/avatar.jpg`；没有将它算作主题运行时请求，也没有删除历史链接。
- 图片样例的 `intentionally-missing-image.png` 是已说明的故意失效资源，不能据此声称所有站内资源都返回 200；HTTP 200 断言针对主页面。
- 无 JS 检查验证内容与原生导航，不验证主题偏好持久化；无 JS 时增强主题按钮隐藏，当前默认样式为浅色。
- 手机尺寸是桌面 Chrome 的视口模拟，并非真机。未测试 Safari、Firefox、触摸手势或屏幕阅读器；未执行完整 WCAG 审计。
- 未把这次检查当作 Lighthouse 或 Web Vitals 性能结果；D8 另行测量。

## 重复运行

先启动 `pnpm dev`。浏览器检查是可选开发工具，不进入默认构建/CI，也不自动下载 Chromium。需要预先准备可用的 Puppeteer 模块和 Chrome：

```bash
export SYUTOI_PUPPETEER_PATH=/absolute/path/to/installed/puppeteer
export SYUTOI_CHROME=/usr/bin/google-chrome
export SYUTOI_BROWSER_OUTPUT=/tmp/syutoi-d7
node toolbox/check-browser.mjs
```

`SYUTOI_PREVIEW_URL` 可修改预览源地址（不带末尾斜杠）；该脚本针对示例站的根路径结构，子目录部署由隔离 Hexo 测试验证。未设置输出目录时只输出汇总；发生断言失败时以非零状态结束，不写新的成功报告。本次实际使用工作区中已有的 `node_modules/.pnpm/puppeteer@5.5.0/node_modules/puppeteer`，没有把浏览器依赖重新加入主题安装链路。其他自动化版本尚未实测。
