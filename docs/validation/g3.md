# G3：核心页面响应式与无障碍验收

日期：2026-09-22。基于 fbd22ae 及本批修复；Node 20.19.2、Puppeteer 5.5.0、Chrome 151.0.7922.108、axe-core 4.13.0。axe 使用构建后的 example/public，在本机 127.0.0.1:4174 提供静态服务；最终浏览器矩阵复测使用重启后的 127.0.0.1:4000 开发预览；可选功能沿用示例默认关闭配置。

## 发现与修复

- 页头 hero 原本位于 banner/main 之外，axe 报 region。将导航和 hero 包在同一个语义 header 内，内部导航容器改为 div，保持原布局和唯一 banner。
- 长文普通 Markdown 表格在 768/390/320px 下横向滚动但不能 Tab 聚焦，axe 报 scrollable-region-focusable。构建时只给缺少 tabindex 的正文表格补 0，保留原 HTML 字节和作者属性，排除代码高亮布局表格；实际禁用 JS 后方向键滚动成功。
- 人工复核发现粉色分类卡片渐变最亮端白字约 4.02:1，85% 不透明度的小字约 3.38:1。加深该端点，装饰符改为低透明度黑色，避免长文字与装饰重叠时背景被提亮。
- 图片 hero 原遮罩无法保证浅色背景上的白字对比度。加深遮罩，保留图片、波浪与结构；页头焦点轮廓采用白色，适配深背景。

按 sRGB 相对亮度与 alpha 合成计算：新 hero 最弱遮罩叠加纯白图片时白字对比度约 4.762:1；分类卡片粉色最亮端小字约 4.534:1、蓝色约 4.669:1。计算不计文字阴影的帮助，装饰只会加深背景；用户自定义颜色/样式后需要重新检查。

## 自动检查与人工边界

axe 启用 WCAG 2 A/AA、2.1 A/AA、2.2 AA 标签及 best-practice 规则。90 组扫描没有违规，但仍有 color-contrast 的 incomplete：图片/渐变、装饰箭头、横向滚动区外的表格/代码文本。未关闭相关规则，也未将 incomplete 隐藏。

图片与渐变按上述保守颜色计算复核；装饰箭头为 aria-hidden，不作为唯一链接名称；表格与代码保留主题正文/高亮颜色，通过既有阅读样例检查及键盘滚动确认可访问。没有声称每段历史文章的所有隐藏内容均通过自动对比度测量。文字放大是根字号测试，不是浏览器原生缩放；手机为桌面 Chrome 视口模拟。

截图保留在 `/tmp/syutoi-g3-browser-final/` 和 `/tmp/syutoi-g3-a11y-final/`，用于人工查看布局、文字和内容面板。未测试真机、Safari、Firefox、屏幕阅读器或操作系统高对比度模式，不能据此宣称完整 WCAG 合规。搜索/评论/灯箱的独立接入验收沿用 F1/F2/E4a，本批不连接外部服务。
