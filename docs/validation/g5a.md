# G5a：独立 Git 安装验收

日期：2026-09-23。被验证提交：`d747660`。Node 20.19.2 / pnpm 9.0.4 / Hexo 8.1.2，Linux。当前包版本 0.4.0，但该提交包含 v0.4.0 标签之后的改动。

## 安装方式

从本地仓库通过 `git clone --no-hardlinks` 克隆已提交主题到独立临时博客的 `themes/syutoi`，没有复用工作区 node_modules 或示例站配置。安装主题生产依赖时使用冻结锁文件；博客依赖使用快速开始中的安装命令，首次产生锁文件后再次冻结安装。主题生产依赖重装也通过，主题目录中未安装 esbuild，无需构建源码即可使用已提交的 JS/CSS。

博客 YAML 直接从快速开始文档读取；测试内容和主题可选配置由验收工具生成。验收没有发现安装阻塞问题。
