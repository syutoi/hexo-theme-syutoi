# F1 本地搜索验收

2026-09-21。Pagefind 1.5.2，Node 20.19.2、pnpm 9.0.4、Hexo 8.1.2，Linux Chrome 151.0.7922.108 / Puppeteer 5.5.0。F1 记录于 Unreleased，保留 `v0.1.0`、`v0.2.0` 原有标签。

## 结果

- lint、typecheck、clean/build/test 通过；53 项测试、19 类页面、20 个样例入口与 Markdown/资源预算检查通过。默认示例站生成 106 个文件，搜索配置保持 none。
- 实际 Hexo generator 在写 public 前提供 Pagefind 内存路由；watch 监听修改文章后自动生成新分片；后续 generate 写出新索引并清理旧分片。删除文章得到空索引，关闭搜索后搜索页和所有索引路由移除。
- 内容过滤覆盖标题/正文/代码、中英文、独立 Page、重复 URL、草稿、未来文章、密码内容和 search: false。Pagefind 只接收正文记录，没有导航、页脚等模板内容。
- 搜索专项：1440/390/320px × light/dark，通过中文查询、英文查询、独立页面、子目录 URL、10 条结果分页、“显示更多”焦点、清空、无结果、字面标题/摘要与无横向溢出检查。空查询与模拟输入法组合事件不会启动引擎。
- 普通页面只有搜索链接，无搜索 JS/CSS/索引请求；搜索页首次查询前只有独立入口/样式。入口下载失败和无 JS 时保留可读的归档回退；manifest、模块和 WASM 的服务器故障均显示错误，恢复后可重新提交。
- 清空后不显示旧的延迟响应。所有成功及故障场景无未捕获页面异常。Pagefind 构造函数的孤立 rejection 通过固定版本、严格匹配的生成适配解决，错误仍传递给搜索调用者，细节见 [决策](../decisions/local-search.md#固定版本的错误处理适配)。
- 默认站点 176 组页面/视口/深浅检查、66 组无 JS 回归通过，无未捕获脚本错误。核心 JS/CSS 字节与 0.2.0 一致，分别为 2028/5382 bytes gzip。

证据：[专项报告](f1-browser.json)、[默认回归](f1-regression.json)、[入口预算](f1-budget.json)。重复运行方式见 [开发文档](../development.md#本地搜索回归)。测试服务器通过 HTTP 503 注入故障，包括 Worker 的资源下载；没有用旧 Puppeteer 的请求拦截代替真实 Worker 网络检查。

## 可选资源成本

搜索入口 JS 为 3350 bytes / gzip 1485，CSS 为 997 / gzip 435。两者单独进入 <6 KB / <3 KB gzip 预算，不并入核心资源。实际数字见预算报告。

14 条公开内容的样本站点中，Pagefind JS 为 45666 bytes / gzip 13012，Worker 为 41366 / gzip 12065，WASM 文件为 68024 bytes（原文件已压缩，再 gzip 为 68067）。整个生成索引目录为 158238 bytes，逐文件 gzip 合计 96703 bytes；包含入口 manifest 和全部分片，不等于首次查询全部下载。浏览器记录按需请求，索引体积随内容变化，不将样例数字作为任意博客的上限。

未分发或加载 Pagefind 预制 UI、高亮器与它们的 CSS。生产依赖仍会安装 Pagefind 平台二进制；关闭开关只保证不启动索引器、不生成索引、不产生浏览器请求，并非零安装成本。

## 范围限制

本次没有重跑 Lighthouse，未测真实用户 INP、大型博客索引性能、Safari/Firefox、真机输入法及屏幕阅读器。手机宽度是桌面 Chrome 视口模拟。单站点语言索引支持样例中的中英文查询，但不提供翻译搜索、简繁转换或任意子串匹配保证。网络错误可重试，不代表离线搜索或跨部署版本的永久缓存支持。
