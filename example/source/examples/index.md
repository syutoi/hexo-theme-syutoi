## 列表与导航

检查 [首页](/)、[归档](/archives/)、[分类](/categories/)、[标签](/tags/) 和 [友链](/friends/)。文章页底部可以前后跳转，目录与分页使用普通链接。

## 使用这些示例

- 切换浅色、深色和自动模式，比较正文与控件的可读性。
- 在桌面与手机宽度下查看表格、长代码和长标题。
- 使用 Tab、Enter、Space、Escape 和方向键操作导航、折叠内容与代码滚动区。
- 禁用 JavaScript 后重新加载，确认正文、目录、分页、图片和 details 仍可用。

图片示例中有一个**故意失效的图片地址**，用于检查替代文字；它不是待修复的资源。复制按钮需要浏览器 Clipboard API，没有该 API 时仍可手动选中代码。

公开文章仅保留欢迎文章、长文和随笔。旧主题文档与课程笔记已移出展示站，必要的兼容测试材料保存在仓库的 `test/fixtures/legacy/`。当前安装与使用文档位于 `docs/`。
